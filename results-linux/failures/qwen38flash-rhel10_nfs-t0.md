*   **NFS with TLS Support**: RHEL 10 fully supports Transport Layer Security (TLS) for NFS RPC traffic. This matters because it ensures encrypted communication between clients and servers, enhancing security, though it relies on kernel TLS (kTLS), which is currently a Technology Preview.
*   **ReaR IPv6 URL Parsing Fix**: ReaR now correctly parses IPv6 addresses enclosed in square brackets within `nfs://` URLs (e.g., `nfs://[::1]/path`). This matters because it allows users to specify IPv6 addresses in backup output URLs without encountering premature abort errors or needing manual shell escaping workarounds.
*   **FS-Cache Integration for NFS**: NFS caching leverages FS-Cache to improve performance, reduce server load, and enable efficient local data retrieval. This matters because it allows clients to satisfy read requests locally, reducing network bandwidth consumption and server load, although it may introduce some client-side latency.
*   **NFS Mount Option Updates**: The `vers` option is now identical to `nfsvers` for compatibility. Additionally, `rsize` and `wsize` defaults are clarified to use the largest value supported by both client and server, with a maximum of 1,048,576 bytes in RHEL 10. This matters for ensuring compatibility with older systems and optimizing transfer sizes for performance.
