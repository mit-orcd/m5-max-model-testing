*   **NFS with TLS support is fully supported**: NFS now supports Transport Layer Security (TLS) for RPC traffic, ensuring encrypted communication between clients and servers. This matters for enhancing security, though it relies on kernel TLS (kTLS), which is currently a Technology Preview.
*   **ReaR correctly parses IPv6 addresses in NFS URLs**: The ReaR tool no longer misinterprets square brackets in `nfs://` URLs containing IPv6 addresses, allowing users to specify IPv6 NFS servers in backup/output URLs without manual escaping workarounds.
*   **Default `rsize` and `wsize` increased to 1,048,576 bytes**: The maximum bytes for single NFS read/write operations are now capped at 1 MB (up from previous defaults), allowing for larger data transfers per operation and potentially improving throughput.
*   **NFS client-side caching via FS-Cache is supported**: The system supports leveraging FS-Cache to cache NFS content locally, which improves performance by reducing network traffic and server load, though it may introduce local I/O latency.
