- **NFS with TLS support (RHEL 10.0)** – Added full TLS support for NFS RPC traffic, enabled via kernel TLS (kTLS).  This adds encryption to NFS sessions, improving security, and can affect throughput by adding TLS overhead, but it allows secure NFS over untrusted networks.  
- **FS‑Cache client‑side caching for NFS** – RHEL 10 now documents and supports FS‑Cache for NFS shares, using the `cachefiles` back‑end on ext3/4 or XFS.  When enabled, read requests are served from local cache, reducing network traffic and server load, at the cost of local disk usage and possible cache‑miss latency.  
- **IPv6 address parsing bug in ReaR NFS URLs** – Fixed an issue where IPv6 addresses enclosed in square brackets were mis‑interpreted in `sshfs://` or `nfs://` URLs used by ReaR.  After the patch, NFS backup and restore operations can reliably target IPv6 hosts without quoting workarounds, improving reliability and reducing manual configuration errors.
