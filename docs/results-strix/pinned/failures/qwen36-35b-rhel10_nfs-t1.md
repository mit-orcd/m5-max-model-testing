*   **NFS with TLS support is fully supported**: NFS now supports Transport Layer Security (TLS) for RPC traffic, ensuring encrypted communication between clients and servers. This matters for enhancing security, though it relies on kernel TLS (kTLS), which is currently a Technology Preview.
*   **ReaR correctly parses IPv6 addresses in NFS URLs**: The ReaR tool no longer misinterprets square brackets in IPv6 addresses within `nfs://` URLs, allowing users to specify IPv6 addresses for NFS backup/output URLs without manual escaping workarounds.
*   **FS-Cache enables client-side caching for NFS**: The integration of FS-Cache with the `cachefiles` backend allows NFS clients to cache data locally, which improves performance by reducing network traffic and server load, although it may introduce some client-side latency.
