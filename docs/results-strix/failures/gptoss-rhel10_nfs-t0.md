- **NFS with TLS support** – RHEL 10 now fully supports Transport Layer Security (TLS) for NFS RPC traffic.  Clients and servers can encrypt all NFS communication, providing stronger data confidentiality and integrity without changing the NFS protocol itself.  
- **IPv6 address parsing bug fix for `nfs://` URLs** – The shell no longer mis‑interprets square brackets in IPv6 addresses used in `nfs://` URLs (e.g., in ReaR `BACKUP_URL` or `OUTPUT_URL`).  This allows users to specify IPv6 addresses directly, eliminating the need for quoting or escaping and preventing premature aborts.  
- **FS‑Cache client‑side caching for NFS** – RHEL 10 introduces the `cachefilesd` service and FS‑Cache integration for NFS mounts.  Cached NFS data is stored locally on a block‑based filesystem (XFS, ext3, ext4), reducing network traffic, lowering server load, and improving client read performance.
