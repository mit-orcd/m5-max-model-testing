*   **NFS with TLS Support**: RHEL 10 fully supports Network File System (NFS) with Transport Layer Security (TLS) for RPC traffic. This matters because it ensures encrypted communication between NFS clients and servers, enhancing security, though it relies on kernel TLS (kTLS) which is currently a Technology Preview.
*   **ReaR IPv6 Support for NFS URLs**: Fixed a bug where ReaR (Relax-and-Recover) failed to parse NFS URLs containing IPv6 addresses enclosed in square brackets (e.g., `nfs://[::1]/path`). This matters because administrators can now use IPv6 addresses directly in `OUTPUT_URL` or `BACKUP_URL` settings without requiring manual quoting or backslash workarounds.
*   **FS-Cache Integration for NFS**: Documentation details the use of FS-Cache with the `cachefiles` backend to cache NFS content locally. This matters because it improves performance by satisfying read requests locally, reducing network bandwidth consumption and server load, although it may introduce some client-side processing overhead.
