Pinned: everything the harness controls, held identical

The main tables above are each machine's ordinary sweep, and those sweeps are not identical: two of three trials run at temperature 0.7, the Mac usually serves MLX where Linux serves llama.cpp, and C is compiled with the box's own libc under -std=c11 (glibc hides strdup; Apple's libc does not). A pinned run (scripts/run-pinned.sh) removes every one of those: the same GGUF, the same llama.cpp fork build, 4 slots × 4096 ctx, temperature 0 with seed 42 on all three trials, reasoning_effort=none on every request, and -std=gnu11. What is left is the GPU backend and the box's toolchain, listed per model below.
