- **Fixed ReaR handling of IPv6 addresses in NFS URLs** (Excerpt 3): Previously, using IPv6 addresses (e.g., `nfs://[2001:db8:ca2:6::101]/`) in `BACKUP_URL`/`OUTPUT_URL` caused ReaR to abort due to incorrect bracket interpretation. Now correctly parses brackets, enabling IPv6-based NFS mounts without workarounds. *Matters because it resolves a critical failure point for IPv6 NFS deployments in backup workflows.*
- **Added client-side caching via FS-Cache for NFS** (Excerpt 5): Enables transparent client-side caching using `cachefilesd` (with XFS/ext4/xfs backends) to reduce network traffic and server load by serving reads from local cache. *Matters because it directly improves NFS client performance and reduces server load for frequently accessed data.*
