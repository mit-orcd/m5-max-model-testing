- **RHEL 10.0 Release Notes — New features**: NFS with TLS support is now fully supported, enabling encrypted communication between clients and servers for enhanced security. This matters because it adds encryption to RPC traffic, though kernel TLS (kTLS) is still a Technology Preview.
- **RHEL 10 Managing file systems — Common NFS mount options**: The maximum `rsize` and `wsize` values are now 1,048,576 bytes by default, allowing larger I/O operations for improved performance between NFS clients and servers.
- **RHEL 10 Managing file systems — Enabling client-side caching of NFS content**: FS-Cache is available to improve NFS performance by caching content locally, reducing server load and network bandwidth usage. This matters because it allows transparent local data retrieval and better handling of read requests without altering basic NFS operations.
