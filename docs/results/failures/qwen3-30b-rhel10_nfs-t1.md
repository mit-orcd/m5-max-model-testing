- NFS client now correctly handles IPv6 addresses in `nfs://` URLs (e.g., `nfs://[2001:db8::1]`), resolving a bug that previously caused mount failures and required workarounds like escaping brackets. This matters for clients using IPv6-based NFS servers without manual configuration.  
- Default `rsize` and `wsize` values increased to 1,048,576 bytes (1 MB), improving NFS transfer efficiency by reducing network round trips per operation. This matters as larger block sizes enhance throughput for both client and server performance.  
- Client-side caching via FS-Cache (using `cachefilesd`) is now enabled by default for NFS mounts, reducing network traffic and server load by caching frequently accessed data locally. This matters for improving read performance and lowering latency in high-traffic NFS environments.
