- **NFS with TLS support** – RHEL 10 now offers fully‑supported NFS over TLS (using kernel TLS). This encrypts RPC traffic between NFS clients and servers, improving security and reducing the risk of traffic interception; it also enables newer security‑level options (krb5p) that can affect performance‑vs‑security trade‑offs.  

- **IPv6 address handling in nfs:// URLs** – Fixed a bug where IPv6 addresses in `nfs://` or `sshfs://` URLs had to be escaped with backslashes. The update correctly interprets bracketed IPv6 addresses (e.g., `nfs://[2001:db8::101]/...`), allowing clients to specify IPv6 endpoints directly in `BACKUP_URL`/`OUTPUT_URL` without work‑arounds, improving usability and reliability for IPv6‑based NFS deployments.  

- **Client‑side caching for NFS via FS‑Cache** – Introduced NFS client‑side caching using the `cachefilesd` daemon and the `cachefiles` back‑end. This leverages FS‑Cache to store frequently accessed NFS data locally, reducing network traffic and server load while providing faster read performance. The feature is transparent to users and can be enabled with a mount option, offering a performance boost for NFS workloads.
