* **NFS with TLS support:** Adds support for Transport Layer Security (TLS) via kernel TLS (kTLS). This enhances security by enabling encrypted communication between clients and servers for RPC traffic.
* **ReaR IPv6 support fix:** Fixed an issue where square brackets in IPv6 addresses were incorrectly interpreted as shell metacharacters when using `sshfs://` or `nfs://` schemes in `BACKUP_URL` or `OUTPUT_URL`. This allows for successful automated backups using IPv6 addresses in these URLs.
* **NFS client-side caching (FS-Cache):** Introduces/documents the use of `cachefiles` and `cachefilesd` to enable client-side caching of NFS content. This can significantly reduce network bandwidth and server load by satisfying read requests from a local block-based file system (XFS, ext3, or ext4).
* **NFS transfer size limits:** The maximum `rsize` and `wsize` (read/write size) is set to 1,048,576 bytes in RHEL 10. This defines the maximum amount of data transferred in a single operation, impacting throughput and efficiency.
