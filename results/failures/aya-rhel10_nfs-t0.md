- **NFS with TLS support**: RHEL 10 offers NFS with Transport Layer Security (TLS), enhancing security by encrypting communication between clients and servers using TLS for Remote Procedure Call (RPC) traffic. This feature relies on kernel TLS (kTLS), provided as a Technology Preview.
- **IPv6 address parsing**: The issue where using an IPv6 address in a sshfs:// or nfs:// URL would cause ReaR to abort prematurely has been fixed. Now, you can use IPv6 addresses enclosed in brackets in BACKUP_URL and OUTPUT_URL without issues.
- **NFS client performance and caching**: RHEL 10 introduces FS-Cache, which leverages client-side caching to improve NFS performance, reduce server load, and enable efficient local data retrieval. FS-Cache works transparently, allowing direct interaction between the client's local cache and the server without requiring an over-mounted file system. It requires a block-based file system (XFS, ext3, or ext4) as a cache back-end.
