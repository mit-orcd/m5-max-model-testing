* **NFS with TLS support:** Adds support for Transport Layer Security (TLS) via kernel TLS (kTLS). This enhances security by enabling encrypted communication between clients and servers for RPC traffic.
* **ReaR IPv6 bracket fix:** Fixed an issue where square brackets used for IPv6 addresses (e.g., `[::1]`) were incorrectly interpreted as shell metacharacters in `sshfs://` or `nfs://` URLs. This allows for successful automated backups/recovery using IPv6 addresses in `BACKUP_URL` or `OUTPUT_URL`.
* **FS-Cache (Client-side caching):** Provides a mechanism to use local block-based file systems (XFS, ext3, ext4) as a cache back end via the `cachefiles` kernel module and `cachefilesd` daemon. This improves performance and reduces network/server load by satisfying read requests locally.
* **NFS Transfer Sizes:** The maximum `rsize` and `wsize` (read/write size) is set to 1,048,576 bytes in RHEL 10. This allows for larger data transfers per operation compared to older standards.
